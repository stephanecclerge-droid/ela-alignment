# ELA Alignment

A standards-first tool that helps NYS Common Core ELA teachers check whether a lesson actually aligns to a specific standard — and explains what that standard really demands, in plain language, for both the teacher and their students.

Starting scope: 10th grade, all ELA strands (Reading, Writing, Language, Speaking & Listening). Built as a supplement that deepens a teacher's own subject and standards knowledge — not a replacement for their judgment.

Stack: Next.js, Supabase, Claude (Anthropic API), Vercel.

Status: Phases 0–6 complete — real authentication, database with row-level security, live AI lesson analysis, and privacy/compliance pages all working end to end. Next: deployment verification and a pilot with real teachers.
